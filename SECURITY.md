# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately using
[GitHub's private vulnerability reporting](https://github.com/Roxxas96/uptime-kuma-operator/security/advisories/new)
(Security tab → "Report a vulnerability") rather than opening a public
issue. This lets us assess and fix the issue before it's disclosed.

Include enough detail to reproduce the problem: affected version(s),
the chart values or Kubernetes resources involved, and expected vs.
actual behavior.

## Supported Versions

Only the latest published release is supported. There is no long-term
support branch at this stage of the project.

## Scope

This covers the operator binary, its Helm chart, and the container
image published from this repository. It does not cover Uptime Kuma
itself — report issues there upstream at
[louislam/uptime-kuma](https://github.com/louislam/uptime-kuma).
